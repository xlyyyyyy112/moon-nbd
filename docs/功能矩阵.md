# MoonNBD 客户端 / 服务端功能矩阵

本文按当前实现梳理协议功能边界。标为“支持”的能力以代码和自动化测试为依据；“有条件支持”表示依赖导出后端所公告的能力或对端实现。

| 功能 | 客户端 | 服务端 | 说明 |
| --- | --- | --- | --- |
| TCP 与握手 | 支持 | 支持 | 固定新式握手；客户端拒绝旧式握手。客户端可在 GO 不可用时尝试新式握手内的旧导出协商回退。 |
| 导出选择与查询 | 支持 | 支持 | 支持默认/命名导出、LIST、INFO、GO；服务端每次连接只提供一个配置的导出。 |
| 简单与结构化读取 | 支持 | 支持 | 结构化读取可重组分块、检测缺块和重叠；服务端按请求返回数据。 |
| 写入 | 支持 | 支持 | 仅当导出非只读；服务端写入内存或普通文件。客户端写操作中断时可能报告结果未知。 |
| FLUSH | 有条件支持 | 有条件支持 | 客户端检查导出标志；文件后端执行同步，内存后端不公告 FLUSH。 |
| TRIM / 写零 | 有条件支持 | 有条件支持 | 客户端支持两种命令；内存后端支持，普通文件后端不公告这两项能力。 |
| CACHE 提示 | 有条件支持 | 支持 | 客户端只发送提示；提示成功不保证数据已进入缓存。当前服务端公告 CACHE 能力。 |
| 结构化元数据 `base:allocation` | 支持 | 支持 | 客户端可协商上下文、扫描块状态和汇总；当前服务端返回区段状态，但不跟踪底层稀疏文件的真实分配图。 |
| 镜像传输与校验 | 支持 | — | CLI/API 支持完整及稀疏导出、导入、比较、差异复制和 CRC32 清单。 |
| 后端与监听 | — | 支持 | API 提供内存和普通文件后端；CLI `serve` 使用普通文件，并只监听 `127.0.0.1`。 |
| 并发与安全 | 单连接串行 | 单连接串行 | 同一连接不支持并发请求；CLI 服务端一次处理一个连接。未实现 TLS 或身份认证。 |

## CLI 功能对应

| 命令 | 角色 | 功能 |
| --- | --- | --- |
| `list`、`info` | 客户端 | 查询远端导出列表、容量与能力标志。 |
| `read`、`export`、`export-sparse` | 客户端 | 读取指定范围、完整导出或按已知零区段进行稀疏导出。 |
| `import`、`verify` | 客户端 | 导入本地镜像；比较本地文件与远端导出并报告差异。 |
| `allocation` | 客户端 | 查询远端 `base:allocation` 状态摘要。 |
| `serve` | 服务端 | 以只读方式导出本地普通文件；显式使用 `--write` 后允许写入。 |

## 明确不在当前范围内

- 旧式（oldstyle）NBD 握手、TLS、用户名密码或其他身份认证。
- 单连接多请求并发，以及面向不可信网络的公网监听配置。
- 普通文件后端的 TRIM、写零和真实文件系统稀疏分配状态报告。
- 内存后端持久化；进程退出后内存镜像数据会丢失。
